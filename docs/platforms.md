# 平台能力矩阵与接入路线

本文是发布平台能力的唯一权威说明。代码侧以
`backend/app/publish/registry.py` 为准：`capability_for(platform, content_kind)`
是执行前的唯一门禁，前端表单、发布页提示与 worker 选路都从同一张表派生。

## 三种能力状态

| 状态 | 含义 | 系统行为 |
| --- | --- | --- |
| `auto_publish` | 官方接口自动发布 | worker 调用官方接口，成功后写回外部 ID；失败写明确错误码 |
| `manual_export` | 导出素材包，人工发布 | 生成 zip（manifest、正文/视频、发布指南），不调用任何平台接口 |
| `pending` | 官方接口未接入 | 可保存账号与凭据，执行时返回明确提示，**不产生假成功** |

## 能力矩阵

| 平台 | 图文 | 笔记 | 视频 | 凭据 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 公众号 | 自动（草稿） | — | — | AppID / AppSecret | 仅创建草稿，群发由人工在后台完成 |
| 抖音 | — | — | 自动 | Client Key / Secret / OpenID / Refresh Token | 开放平台视频发布 |
| 头条 | 待接入 | — | 自动 | Client Key / Secret / OpenID / Refresh Token | 图文接口未获批 |
| 小红书 | 手动导出 | 手动导出 | — | 无 | 导出素材包 |
| 知乎 | 手动导出 | — | — | 无 | 导出素材包 |
| 快手 | — | 手动导出 | 手动导出 | 无 | 导出素材包 |
| 视频号 | 手动导出 | — | 手动导出 | 无 | 导出素材包 |
| 百家号 | 待接入 | — | — | AppID / App Token | 官方接口未接入，可先存凭据 |
| B站 | — | — | 待接入 | 无 | 暂无公开发布接口，可先存账号 |

同一平台支持多账号；凭据加密存库，接口只返回掩码。

## 接入优先级

1. **头条图文**（`toutiao` / `article`）：优先与官方确认图文接口的资质与开放范围；获批后复用
   `OpenPlatformVideoAdapter` 的令牌刷新与错误脱敏逻辑，新增图文创建适配器，把注册表条目从
   `pending` 改为 `auto_publish`。
2. **百家号**（`baijiahao` / `article`）：需要官方发布接口授权；适配器骨架已存在，补齐上传与创建
   两个请求即可，其余门禁无需改动。
3. **B站**（`bilibili` / `video`）：目前无公开发布接口，保持 `pending`；只维护账号与凭据。
4. **manual_export → auto**：小红书、知乎、快手、视频号能否转自动，完全取决于各平台开放平台是否
   提供内容发布权限与企业资质。未获批前继续导出，不做逆向接口、不模拟点击。

## 非目标

- 不使用逆向接口、抓包重放或自动化点击绕过官方限制。
- 不在能力缺失时伪造成功状态；`pending` 一律返回可读提示。
- 发布与排期不进入 Agent/工作流/团队的工具集，AI 侧只能创建草稿任务。

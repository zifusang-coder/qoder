# 清爽主题迁移实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把前端从深色 slate + indigo 主题迁移为白灰底、自然绿主色、酒红点缀的清爽主题，且不改变任何业务行为。

**Architecture:** 在 `web/src/index.css` 用 Tailwind v4 `@theme` 定义 `paper/surface/ink/sage/wine/warm` 设计令牌，并提供 `card/input/btn-*/nav-link` 组件类。先用测试锁住令牌与组件类，再手工迁移品牌外壳（`Layout`、`Login`、`auth-context`），最后用一次性 Node 脚本按固定映射批量替换 14 个页面/组件中的旧色板，并加一条全仓库守卫测试防止回退。

**Tech Stack:** React 19、Tailwind CSS v4、Vitest、Vite 8。

- [ ] **Step 4: 迁移 `Login.tsx`**

把 `web/src/pages/Login.tsx` 全文替换为：

```tsx
import { FormEvent, useState } from "react";
import { api, setToken } from "../client";

export default function Login() {
  const [email, setEmail] = useState("admin@local");
  const [password, setPassword] = useState("");
  const [error, setError] = useState("");
  const [loading, setLoading] = useState(false);

  async function submit(event: FormEvent) {
    event.preventDefault();
    setLoading(true);
    setError("");
    try {
      const data = await api<{ access_token: string }>("/auth/login", {
        method: "POST",
        body: JSON.stringify({ email, password }),
      });
      setToken(data.access_token);
      // AuthProvider snapshots the token on mount; a full reload guarantees it
      // picks up the fresh session before routing to the protected layout.
      window.location.assign("/");
    } catch (err) {
      setError(err instanceof Error ? err.message : "登录失败");
    } finally {
      setLoading(false);
    }
  }

  return (
    <main className="card mx-auto mt-24 w-full max-w-sm p-8">
      <h1 className="text-xl font-semibold text-ink-900">云AI新媒体运营系统</h1>
      <p className="mt-1 text-sm text-ink-500">登录后开始创作与发布</p>
      <form className="mt-6 space-y-3" onSubmit={submit}>
        <input
          className="input"
          aria-label="邮箱"
          required
          value={email}
          onChange={(e) => setEmail(e.target.value)}
          placeholder="邮箱"
        />
        <input
          className="input"
          aria-label="密码"
          required
          type="password"
          value={password}
          onChange={(e) => setPassword(e.target.value)}
          placeholder="密码"
        />
        {error && <p className="text-sm text-wine-600">{error}</p>}
        <button className="btn-primary w-full" disabled={loading}>
          {loading ? "登录中…" : "登录"}
        </button>
      </form>
    </main>
  );
}
```
